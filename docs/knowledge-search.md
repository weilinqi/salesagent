# 知识检索使用与配置

知识模块现支持中文关键词、常见销售同义词和语义混合检索，结果合并排序并去重。内部资料与公开网络资料分别展示。

## 使用方式

- **本地优先，自动联网补充**：页面默认模式。本地结果不足时将搜索词发送给 MiniMax，不将内部文档内容发送到联网搜索。
- **仅内部知识库**：不调用联网搜索，适合内部产品、报价或其他不应外发的查询。
- **仅联网搜索**：直接搜索公开资料，展示标题、摘要、来源链接和服务返回的日期（如有）。

内部检索不可用会显示提示；联网失败会保留本地结果。没有结果时可尝试产品全称、型号、同义词或完整问题。

## MiniMax 配置

在本地 `backend/.env` 配置，真实密钥不要提交到 Git：

```dotenv
MINIMAX_SEARCH_API_KEY=
MINIMAX_API_HOST=https://api.minimaxi.com
MINIMAX_USE_PROXY=false
```

搜索密钥为空时复用 `MINIMAX_API_KEY`。该账户必须具有搜索接口权限；对话调用成功不代表搜索权限也可用。国际站使用 `https://api.minimax.io`，密钥应与站点匹配。重启后端后生效。

本次复用项目现有的 MiniMax 搜索适配器；对话/语音三重凭证兜底保留，搜索失败单独显示降级提示，不宣称搜索接口也具有三重兜底。实现中不自动重试搜索，以免重复消耗额度。

## API 兼容性

`POST /api/v1/knowledge/search` 仍要求登录。原有 `query`、`top_k`、`source_filter`、`category` 和返回字段保留；新增 `mode`（`local` / `auto` / `web`），旧客户端不传时默认 `local`。

新增返回字段：`web_results`、`notices`、`mode`。`total` 仍仅表示返回的内部结果数。分类和来源筛选在本地取候选之前执行；存在这些筛选时，自动模式不外发查询。显式 `web` 模式只搜索网络，内部筛选不适用于网络。

自动联网使用保守的相关度规则，不将检索分数当作答案正确率。后续应以实际失败查询评估阈值和同义词，补充词条，而不是依赖任意词都能返回结果。
