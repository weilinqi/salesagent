# 对练历史恢复

在“练习历史”选择进行中的会话，点击“继续”。页面将先从服务器加载原会话消息、角色配置、客户背景、访前准备和练习目标，再连接该会话。刷新页面或换浏览器后也以服务端保存的会话为准。

已结束的会话可以点击“查看对话”，仅查看记录，不会重新开启会话。历史读取失败时显示重试入口，不会跳到另一个缓存会话或创建新会话。

后端重连会恢复已保存的消息上下文，并保留客户身份，不再重复生成开场。新生成的客户身份和正式开场白也会保存。声音设置保留，但历史消息的录音和语音回放数据未新增存储。

已有数据库无需迁移。继续使用原来的数据库文件和数据卷；不要用空数据库覆盖历史。此前未保存的开场白、生成角色或其他内容无法事后重建。

开发接口（均要求登录且只能读取自己的会话）：

- `GET /api/v1/practice/sessions/{session_id}`：原会话信息，新增场景、阶段、客户背景、调查结果、用户练习档案及客户身份快照。
- `GET /api/v1/practice/sessions/{session_id}/messages`：按创建时间和 ID 排序的已保存消息。

更新后需要重新启动后端并重新构建或重启前端，部署到线上时保留现有持久化数据。本次不更改 MiniMax 联网和模型连接配置。
